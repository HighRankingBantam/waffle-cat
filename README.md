# Waffle Cat Classic

The one Classic backup. Fork of [OldJobobo/waffle-cat](https://github.com/OldJobobo/waffle-cat) pinned to **`alpha-final` (`dd1bd2b`)** — last commit **before 2.0** — plus the Omarchy theme and the full wallpaper pack.

2.0 lives on upstream `master`. This fork stays on the classic palette (`#ffbe55` honey gold on `#292025`).

## What’s here

- Colorscheme at `alpha-final` (`colors/`, `palette/`, `configs/`, neovim, generators)
- `omarchy/` — pre-2.0 Omarchy theme (Hyprland, GTK, terminals, Vencord, **24 wallpapers**: classic 18 + six from 2.0)

Accent: `#ffbe55`. Background: `#292025`.
